Restore:
pg_restore -U postgres -d vtc -c -F c -v /app/data/backups/vtc_backup_2025_10_02_0011.dump
-c - clean objects before recreating
-F c - custom format
-v - verbose

Back up:
pg_dump -U postgres -h localhost -p 5432 -F c -v -f /app/data/backups/vtc_full_backup_2025_10_27_1822.dump vtc
-f filename

for pg_restore and for pg_dump -h and -p are used to run outside of container. (might require a password)

Copy:
scp /path/to/local/file username@vps_ip:/path/to/remote/directory/
scp backup_and_restore_instructions.txt %username%@%vps_address%:/home/%username%/vtclips-analytics/data/backups
To copy the other way around switch source and destination (duh)
